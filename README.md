# Budget Planner — versie 11

## Op GitHub publiceren
1. Pak dit ZIP-bestand uit.
2. Upload de inhoud naar je bestaande GitHub-repository: index.html, sw.js, manifest.json, lucide.min.js, de map icons en .nojekyll. Behoud de mapstructuur.
3. Open Settings → Pages, kies Deploy from a branch, main en / (root), en klik op Save.
4. Open de GitHub Pages-link zodra de publicatie klaar is.

## Op je telefoon
Op iPhone: open de link in Safari, tik op Delen → Zet op beginscherm.
Op Android: open de link in Chrome en kies Installeren of Toevoegen aan startscherm.

Open de app de eerste keer met internet. Daarna kan de planner offline openen. De gegevens blijven lokaal op hetzelfde apparaat en in dezelfde browser; gebruik de ingebouwde back-upfunctie vóór een update. Houd je bestaande GitHub-adres om je lokale gegevens te behouden. Sluit en heropen de app na het bijwerken als je nog een oude versie ziet.

## Versie 11
- Minimalistische vermogensgrafiek met één verandering ten opzichte van de vorige maand.
- Totale groei, beste maand en slechtste maand; geen hoogste/laagste stand.
- Compacte informatie in twee kolommen op telefoonformaat.
- Herstelde offlinebestanden en bijgewerkte cache.

AI Gateway vereist een aparte server en werkt niet zelfstandig op GitHub Pages. De gewone planner werkt zonder AI.
